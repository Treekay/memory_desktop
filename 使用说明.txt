Memory Desktop · 使用说明

1. 解压到长期保留的目录，双击 MemoryDesktop.exe，无需管理员权限。
2. 右键任务栏通知区域的青绿色照片图标 → 选择照片文件夹…。
3. 两张较大的照片在不同区域分别出现、停留、消散，不相互重叠。
4. 背景 → 深色留白 / 梦境星空，可以随时切换比较，选择会保存在本机。
5. 停留时间 → 6–8 秒 / 9–12 秒 / 11–17 秒；默认 6–8 秒，不含淡入淡出，选项保存并打勾，各自下一张生效。
6. 暂停 / 继续控制照片和背景；退出恢复原来的桌面背景。
7. 登录 Windows 时启动默认关闭，仅手动勾选才开启；删除或移动程序前先取消。

只读取你选定文件夹的直接图片，不含子目录，不上传照片。支持 JPG、PNG、BMP、GIF、TIFF；暂不支持 HEIC、RAW、视频。损坏图片会跳过。

设置位于 %LOCALAPPDATA%\MemoryDesktop\settings.xml。
当前实际验证为 Windows 11 25H2，Windows 10 是兼容目标、尚未实机验证。
桌面挂载使用非官方 Explorer 机制，系统更新或第三方桌面工具可能影响显示。
构建、测试与详细限制请看 README.md 和 VERIFICATION.md。
